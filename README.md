# water-remainder

一个 Windows 桌面喝水提醒工具：常驻托盘、定时弹窗提醒，并记录每一次喝水打卡，形成月历热力图与时间轴。

---

## 功能

- **定时提醒** — 到点后全屏浮层提示「该喝水了」，可选择「喝了」或「跳过」；浮层上「上次喝水 / 下次提醒」两处倒计时按秒实时跳动，并附具体时刻
- **智能顺延** — 提醒时间基于**最近一次喝水记录**计算；休眠唤醒后自动重新计算，不会因为合盖而漏提醒
- **喝水记录** — 每次打卡都会本地记录，主窗口以月历热力图 + 当日时间轴展示
- **间隔可调** — 15 ~ 75 分钟，步进式调节（默认 45 分钟）
- **提醒图片可换** — 提醒浮层中央的喝水插图可在设置里替换为本地图片（默认用内置图）
- **开机启动** — 登录 Windows 后自动启动
- **单实例运行** — 已运行时再次启动不会再开一个
- **窗口状态记忆** — 主窗口位置、尺寸、最大化状态持久化

## 交互入口

| 操作 | 行为 |
| --- | --- |
| 左键单击托盘图标 | 打开 / 唤起主窗口（记录日历） |
| 右键托盘菜单「立即提醒」 | 立刻弹出一次提醒浮层 |
| 右键托盘菜单「退出」 | 保存窗口状态并结束进程 |
| 主窗口标题栏齿轮图标 | 打开设置窗口 |
| 主窗口标题栏关闭按钮 | **隐藏**主窗口，进程继续托盘常驻 |
